# Система учёта оборудования в организации

## Описание проекта

Проект представляет собой простую программу для учёта оборудования в организации.

## Цель работы

Научиться работать с Visual Studio Code, Python, Git и GitHub, а также освоить Markdown и PlantUML.

## Возможности программы

- Ввод названия оборудования.
- Добавление оборудования.
- Вывод названия добавленного оборудования.

## Пользователи системы

В системе предусмотрены два пользователя:

- Специалист по учёту оборудования.
- Ответственный сотрудник.

## Используемые технологии

- Python — язык программирования.
- Visual Studio Code — среда разработки.
- Git — контроль версий.
- GitHub — хранение проекта.
- Markdown — оформление документации.
- PlantUML — создание диаграмм.

## Запуск программы

Для запуска необходимо открыть файл `src/main.py` в Visual Studio Code и выполнить его.

## Результат работы

Программа запрашивает название оборудования и выводит его на экран.
